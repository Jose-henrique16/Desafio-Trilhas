# Desafio Trilhas — JavaScript 🚀

Repositório desenvolvido durante meus estudos de programação, reunindo exercícios práticos de **JavaScript** realizados no programa Trilhas.

## 📚 Sobre o projeto

Este projeto reúne 15 exercícios desenvolvidos para praticar os fundamentos da programação e da linguagem JavaScript.

As atividades foram construídas utilizando arquivos JavaScript executados através de páginas HTML, permitindo praticar conceitos básicos de programação de forma gradual.

## 🧠 Conteúdos praticados

Durante os exercícios, foram trabalhados conceitos como:

- Declaração e utilização de variáveis;
- Tipos de dados;
- Operadores matemáticos;
- Operações com valores;
- Template literals;
- `if`, `else if` e `else`;
- Operadores de comparação e lógicos;
- Estruturas de repetição `for` e `while`;
- Funções;
- `prompt()`;
- `alert()`;
- `console.log()`;
- Cálculos utilizando `Math.PI`.

## 📝 Exercícios

O projeto possui 15 questões práticas, incluindo exercícios de:

- Exibição de informações;
- Cálculo de idade e altura;
- Cálculo de desconto;
- Verificação de temperatura;
- Verificação de maioridade;
- Sistema simples de aprovação;
- Comparação entre números;
- Repetição de valores;
- Jogo de adivinhação com número secreto;
- Tabuada;
- Números pares;
- Cálculo da área de um círculo;
- Operações matemáticas;
- Introdução a funções.

## 🛠️ Tecnologias utilizadas

- **JavaScript**
- **HTML**
- **Git / GitHub**
